# Design decisions

The calls that shaped Scout, and why. Newest at the bottom.

| Date | Decision | Why |
|---|---|---|
| 2026-10-14 | Two data sources: the Simplify + Pitt CSC list and the vanshb03 list (MIT). | vanshb03 had 296 postings Simplify lacked, including every Microsoft row. See `reference-report.md`. |
| 2026-10-14 | IT support, help desk, and information technology titles stay in. | Simplify's README generator drops them; Scout reads the raw JSON so they can count. |
| 2026-10-14 | Page-change watching is a small hash-diff in GitHub Actions, not changedetection.io. | No server to run, $0. |
| 2026-10-14 | Nothing is borrowed from projects that auto-apply, log into job sites, or evade bot detection. | Scout never submits anything; the person always does. |
| 2026-10-14 | Resumes are one JSON file per variant plus one HTML template, rendered by WeasyPrint. No LaTeX. | Easier to read and restyle; the template holds no personal data, so it can be public. |
| 2026-10-14 | Company tiers match on the whole company name (minus Inc, LLC, Corp). | A word match ranked "Apple Bank" as Apple. |
| 2026-10-14 | Role exclusions include firmware, electronics engineering, business intelligence, data engineering, and data analysis. | Early runs surfaced those as software roles. |
| 2026-10-14 | Postings older than 90 days lose 10 points; older than 240 days are dropped. | A 375-day-old posting ranked 13th. The lists keep rows "active" long after they close. |
| 2026-10-14 | Freshman and sophomore programs are worth 45 points, so any exploratory program outranks a plain big-company posting. Campus and student ambassador roles are a target role of their own. | Programs built for first- and second-year students are the highest-value finds, and they are rare. |
| 2026-10-14 | Nine watched program pages (Microsoft, Google, NVIDIA, Apple, Amazon, GitHub Campus Experts). Meta, Notion, and Figma are not watched. | Meta answers HTTP 400 to any server fetch; the others are JavaScript apps with no text to compare. Every chosen page hashed identically on back-to-back fetches. |
| 2026-10-14 | A first `--seed` run marks every existing match as seen. | Otherwise the first live run would push dozens of old postings at once. |
| 2026-10-14 | Dependencies split: `requirements.txt` (PyYAML, used by the cron and tests) and `requirements-resume.txt` (WeasyPrint and friends). | Keeps each Actions run to about a minute. |
| 2026-10-14 | A page counts as changed only when new lines appear. Cloud region strings are stripped as noise. | The first cron run pushed a false alarm: Amazon's page names the AWS region that served it. |
| 2026-10-14 | Postings are read through Workday's public JSON endpoint and Google Careers' HTML, as well as Greenhouse, Lever, and Ashby. "Penultimate year", "rising junior or senior", and similar count as ineligible. | Most big-company postings are on Workday or Google Careers, and some are upperclassmen-only. |
| 2026-10-14 | The dashboard gets data by push from the cron (secret header) and sends phone edits back by pull. | The Worker never needs repo write access. (Since 2026-10-16 it holds a token that can only start workflow runs; see below.) |
| 2026-10-14 | The sync sends a named User-Agent. | Cloudflare returns 403 to Python's default User-Agent before the Worker sees the request. |
| 2026-10-14 | Dashboard look: Bowlby One headlines, Rubik body, Titan One wordmark with a bullseye "o", navy outlines with hard shadows, cream cards, one color per page, gold for the main action. Everything lives in `worker/src/tokens.css`. | A playful, poster-like identity that is easy to restyle in one file. |
| 2026-10-15 | Hourly schedule, with the 7:00 PM digest as a once-a-day check inside every run. | GitHub delays and skips scheduled runs; a forced digest schedule once went out at 11 PM. |
| 2026-10-15 | Rotating "latest jobs" carousel cards are stripped from program pages before comparing. | One page swapped its featured job daily and sent a false "page changed" push. |
| 2026-10-15 | A posting that rules you out sinks to the bottom, labeled, never hidden. | An upperclassmen-only posting was ranking third. |
| 2026-10-15 | State lives on a separate `data` branch; `main` holds only code. | Hourly bot commits were burying the real history. |
| 2026-10-15 | Home-screen icons as PNGs plus a web app manifest; gradients and motion that switch off for reduced-motion users. | iOS ignores SVG icons. |
| 2026-10-16 | A one-time `catchup` mode pushes the big tech postings and freshman programs the first `--seed` marked as seen. | The seed swallowed 1,197 matches, so open Tier 1 postings never alerted. |
| 2026-10-16 | The New page counts open matches from `total_matches`, not from the 300 rows the cron uploads. | It said "299 open matches" while far more had passed the filters. |
| 2026-10-16 | A blank degrees field scores the same as Bachelor's listed. | Graduate-only rows are already dropped, and Microsoft SWE rows sat at 56 to 59, just under the instant threshold, only because the field was empty. |
| 2026-10-16 | Tier 1 and 2 postings never take the over-90-days penalty. | Big companies keep one evergreen posting open all season; Apple's undergrad SWE intern posting sat at rank 160. The page check catches the ones that closed. |
| 2026-10-16 | `--dry-run` writes nothing at all, including the eligibility cache and page fingerprints. | A dry run that saved them could hide a page change from the next real run. |
| 2026-10-16 | Stated graduation windows decide eligibility before freshman words, with "or later" floors, "by" ceilings, and "degree expected" phrasing; every row that could push gets its page read; a page that only says nothing pushes quietly. | A product review found 7 of 20 alerts were postings he could not apply to, all labeled "unknown". |
| 2026-10-16 | Postings read through Greenhouse's and Ashby's public APIs, Eightfold (Netflix, Microsoft), and Amazon's HTML; a posting the board says is gone is labeled closed. | Netflix, Notion, Pinterest, and Waymo were unreadable, and a removed Google posting stayed listed. |
| 2026-10-16 | Hardware and graduate-only titles drop even inside a freshman program; "software" in a title beats an exclude word; postings outside the US drop; `us_citizen` in targets.yaml decides citizenship-required postings. | NVIDIA's Ignite hardware track scored 96, Palantir's "Civil Liberties Software Engineer" was dropped for "civil", and a London posting pushed. |
| 2026-10-16 | The Worker runs an hourly heartbeat that starts a GitHub run when none arrived in 50 minutes and warns after 4 hours. | GitHub ran 4 of 22 scheduled runs on October 15. |
| 2026-10-16 | Reposts under a reused title alert when the URL is new and the post date is after the last alert. | Big tech reuses "Software Engineer Intern" for every team and season. |
| 2026-10-16 | `sync push --tracker-only` for /prep and /status. | A full push from the Mac would replace the dashboard's matches with an old copy. |
| 2026-10-16 | Scout also reads the Greenhouse, Ashby, and Lever boards of Tier 1 and 2 companies that use them (Figma, Pinterest, Airbnb, Duolingo, Notion, Spotify), intern and co-op titles only; when a list and a board carry the same posting, the list's row wins. | Figma's Product Design Intern never appeared on either list, which are built around software engineering. |
| 2026-10-16 | A Review page for prep kits, with edits saved on the phone and pulled back into the kit files. Kits live only in KV behind the password. | Opening folders on the Mac to review kits did not work for him; he reviews from his phone. |
| 2026-10-19 | Any title with "fellowship" or "fellows program" counts as an early-career program, and Palantir's Lever board is read. PhD, graduate, and postdoc fellowships still drop. | Palantir's Meritocracy Fellowship never surfaced: no list carries it, and its title names no role. |
| 2026-10-19 | Company board rows skip the 240-day age cutoff. | A board only lists open jobs, and Palantir reposts the same fellowship every year under a 2025 date. |
| 2026-10-19 | A posting that says applicants cannot be enrolled in college is labeled ineligible. | College-alternative fellowships (Meritocracy) rule out a current student whatever the graduation year. |
| 2026-10-19 | Four fellowship pages watched: Apple Swift Student Challenge, MLH Fellowship, Coding it Forward, Kleiner Perkins Fellows. | They have no board Scout can read. Neo Scholars, Google's Generation scholarship, Code2040, and SEO Tech Developer served no readable text. |
| 2026-10-20 | Company logos on every card, from the square logo on each company's Simplify page (`scout/logos.py`), read once per company and cached in `data/logos.json`; rows from other sources borrow the logo by company name; anything else gets a letter badge. | Cards were text only. Favicon services return 16px icons for many companies; Simplify's are 100 to 200px squares, and its robots.txt allows company pages. |
| 2026-10-20 | A borrowed panda mascot on the login, New, Programs, Review, and Tracker pages, with its mood following the page's state. The art is uploaded from the Mac straight into KV (`sync push --mascot`) and never committed; `sync push --mascot --remove` takes it off. | It fills the animated avatar idea (ideas/animated-avatar.md) until Scout gets its own character. The art belongs to another project, so it stays out of this public repo. |
| 2026-10-20 | The mascot is two layers per pose (a still mood circle and leaves, and the panda alone), and only the panda moves, with a slow breath from his feet. Company names never break mid-word; names with a long word get a little smaller. | He wanted the panda to move without the background, and "Verizon Communications" was breaking as "Communicatio / ns". |
